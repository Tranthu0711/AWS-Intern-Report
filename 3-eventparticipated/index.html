Key Takeaways

Design Mindset

Based on the event content, system design thinking has shifted from traditional approaches to a cloud-native and AI-first mindset. Instead of focusing solely on building features, modern design prioritizes scalability, flexibility, and AI integration capabilities.

In particular, system design must now emphasize Developer Experience (DX) and enable automation across the entire software development lifecycle.

Technical Architecture

Modern architectures presented at the event primarily revolve around the Amazon Web Services (AWS) ecosystem, incorporating components such as serverless, containers, and AI services.

A typical architecture includes:

  • Frontend distributed via CDN
  • Backend deployed using containers or serverless
  • AI layer integrated through services like Bedrock
  • End-to-end monitoring and observability

A key highlight is that architecture is no longer siloed—it has evolved into a tightly integrated system combining application + infrastructure + AI.

Modernization Strategy

Modernization strategies focus on transitioning from traditional systems to:

  • Microservices or serverless architectures
  • Automated CI/CD pipelines
  • AI integration into operational workflows

The evolution model from EC2 → containers → serverless reflects a trend toward reducing infrastructure management while increasing focus on business value.

Applying to Work

The knowledge gained can be directly applied to real-world projects:

  • Designing cloud-based system architectures (especially on AWS)
  • Building CI/CD pipelines
  • Integrating AI into products (chatbots, search, recommendation systems)
  • Optimizing system performance and cost

These are essential skills for improving productivity in enterprise environments.

Participating in the “FCAJ Community Day” event provides a multi-faceted learning experience, combining theory and practice. Participants not only gain access to new knowledge but also observe real-world demos, helping them understand how technology is applied to products.

Learning from highly skilled speakers

The speakers were experts in cloud, DevOps, and AI, offering practical insights from production-level projects.

Participants gained a deeper understanding of:

  • Best practices in system design
  • Real-world implementation challenges
  • Performance and cost optimization strategies

Leveraging modern tools

The event introduced various modern tools and services, including:

  • AI services (Bedrock, embeddings, RAG)
  • DevOps and observability tools
  • Container orchestration platforms

These tools help increase productivity and reduce system complexity.

Networking and discussions

The event provided opportunities to connect with experts and peers in the field. Through Q&A sessions and discussions, participants could:

  • Expand professional networks
  • Learn from real-world experiences
  • Exchange solutions to technical challenges

Lessons learned

I gained a lot of practical knowledge about modern cloud architecture and AI application systems, especially multi-agent workflows and system observability. In addition, understanding the role of Amazon CloudFront in improving performance, security, and cost optimization has given me further direction to improve the architecture for the Classic Groove project.

Overall, the event not only provided technical knowledge but also helped me reshape my thinking about application design, system modernization, and cross-team collaboration.
