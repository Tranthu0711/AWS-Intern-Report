This page presents the work log for the Classic Groove project, broken down by week and day.

The work log helps track progress, completed tasks, and any issues that need to be addressed during the development of the declaration system.

The project will be completed within 8 weeks (2 months), with the goal of building and developing a complete web application on a cloud-based operating system (AWS).

**Week 1:** [Studied AWS and cloud computing concepts. Became familiar with EC2 and RDS services. Created an AWS account and configured IAM based on the principle of least privilege.](1.1-week1/)

**Week 2:** [Analyzed project requirements, set up a local environment (LAMP), built and tested the MySQL database. ](1.2-week2/)

**Week 3:** [Launched EC2 (Amazon Linux 2), configured Security Groups (SSH, HTTP, HTTPS), created SSH keys, installed Apache and PHP.](1.3-week3/)

**Week 4:** [Uploaded source code using SCP, deployed it to the /var/www/html directory, configured file permissions, and tested access. ](1.4-week4/)

**Week 5:** [Created RDS MySQL, configured Security Groups (port 3306), connected EC2 to RDS, and imported the database from local.](1.5-week5/)

**Week 6:** [Resolved MySQL 8 connection and charset issues, installed php-mysqlnd, upgraded PHP, and created a script to test database connection.](1.6-week6/)

**Week 7:** [Configured database connection in the source code (dataProvider.php) using mysqli_real_connect (SSL), restarted Apache, and tested the system.](1.7-week7/)

**Week 8:** [Tested the system, debugged errors, checked all functionalities, wrote documentation, and completed the report.](1.8-week8/)
