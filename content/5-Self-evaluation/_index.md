During my internship at AMAZON WEB SERVICES VIETNAM COMPANY LIMITED from 09/03/2026 to 02/05/2026, I had the opportunity to learn, practice, and apply the knowledge I gained at school to a real-world work environment.
I participated in projects using AWS services such as EC2, VPC, RDS, S3, and IAM. Through implementing a 3-tier system, I gained a clear understanding of how to build a complete web system on a cloud platform. 

Specifically, I learned how to:
- Provision and configure EC2 instances for web hosting (Apache, PHP) 
- Set up and manage databases using Amazon RDS (MySQL) 
- Configure networking with VPC and Security Groups for secure communication 
Integrate Amazon S3 for static asset storage 
- Apply IAM policies following the principle of least privilege 

Additionally, I improved my debugging and troubleshooting skills by resolving real-world issues such as database connection errors, charset problems, and environment misconfigurations.

In terms of soft skills, I developed self-learning ability, problem-solving skills, and time management while ensuring project completion within the given timeline.

In terms of work ethic, I always strived to complete tasks well, complied with workplace regulations, and actively engaged with colleagues to improve work efficiency.

### Limitations
Despite the achievements, the internship also revealed several limitations and challenges.
* The first challenge was adapting to a cloud environment. Transitioning from local development to AWS required understanding how different services interact, especially EC2, RDS, and VPC. Misconfigurations in Security Groups or connection settings often caused system failures.
* The second challenge involved troubleshooting technical issues such as MySQL connection errors, charset mismatches, and missing PHP drivers (mysqlnd). Resolving these issues required extensive research and experimentation.
* The third limitation was system design thinking. Initially, I focused on functionality rather than considering scalability, cost optimization, and security.
* Additionally, my ability to quickly understand advanced cloud concepts and technical documentation in English still needs improvement.

Overall, these limitations mainly stem from adapting to a new environment and technology stack, but they also provided valuable learning opportunities.
